# StudyPlanner

Планувальник навчальних завдань (варіант 6). Вебзастосунок на HTML, CSS і JavaScript без серверної частини.

## Запуск
Відкрийте файл `index.html` у веббраузері. Інтернет не потрібен. Структуру папок змінювати не слід.

## Структура
- `index.html` — каркас сторінки
- `css/styles.css` — стилі
- `js/validator.js`, `js/storage.js`, `js/taskManager.js`, `js/filter.js` — логіка
- `js/app.js` — інтерфейс і навігація

Дані зберігаються в localStorage браузера (ключ `studyplanner.tasks`).
